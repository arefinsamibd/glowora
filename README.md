Glowora starter shop

A static, Vercel-ready storefront. No domain or paid hosting is needed to preview or deploy it.

## Deploy to Vercel

Import this folder (`glowora-shop`) as a project in Vercel, or use the Vercel dashboard to create a new project and select this folder. It is plain static HTML, so no build command or output directory is required. Vercel will provide a free `*.vercel.app` address.

## Before taking real orders

- Replace the illustrative catalog in `index.html` with your real product names, prices, descriptions, and photos.
- Replace `name@domainmail.com` with the email address where you want orders sent.
- Add your phone, WhatsApp/IMO, Facebook, Instagram, X, and YouTube details when ready.
- Confirm product availability, authenticity, final prices, and delivery terms.

The checkout currently opens the visitor's email app with the order details addressed to the placeholder email. This starter does not store orders on a server. COD is the only payment option shown. Delivery is set to ৳70 inside Dhaka (about 1 day) and ৳120 outside Dhaka (about 3–5 days).

Catalog examples are illustrative category ideas, not confirmed inventory or endorsed brands. The name `glowora.com.bd` is a suggestion only; availability has not been checked.
